# Live Debate Engine

White-label operating platform for the competitive motion-based debates described in the approved UBC debate specification.

This is independent of the politician-to-politician debate product. Reusable competition rules, workflows, services, and user interfaces belong here. The separate `neophilism/UBC-Debates` repository is the thin branded implementation.

## Status

Repository bootstrap only. The approved E01-E50 engine plan and U01-U04 branded implementation plan will be recorded through a reviewed pull request. No working application, deployment, security certification, or AI qualification is claimed.

This initial README establishes the default branch in the previously empty repository so subsequent changes can use pull requests.
